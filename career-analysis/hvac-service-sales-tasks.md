# HVAC서비스영업팀(서비스영업그룹) 업무 세분화 (2026-11-27)

**표기:** [사실]은 공개 자료로 확인한 내용, [추정]은 사업 구조를 바탕으로 한 추론입니다. 팀의 내부 업무분장은 공개 자료에 없으므로, 면접이나 현직자를 통해 확인해야 합니다.

## 0. 무엇을 파는가 (판매 상품) [사실]
삼성전자 B2B 시스템에어컨 유지보수 상품이고, 실제 수행은 로지텍이 맡는 구조입니다.

**서비스 구성 (5개 분야)**
| 분야 | 내용 |
|---|---|
| 정기점검 | 연 2회, 전문 엔지니어가 방문 |
| 세척 | 종합 세척, 필터 세척 |
| 원격케어 | 스마트싱스 프로 기반 상태 모니터링과 원격 진단 |
| 바로출동 | 고장 접수 24시간, 현장 출동 48시간 이내 목표 |
| 방문수리 | 상품에 따라 보장 범위가 다름 |

**상품 라인업 (2026년 5~6월 B2B 카탈로그 기준)**
| 상품 | 성격 |
|---|---|
| 퍼스트마일케어 | 입문형 |
| 미들마일케어 | 표준 연간 유지보수 |
| 라스트마일케어 | 교체와 결합한 형태 |
| 공기청정 판넬 케어 | 별도 상품 |

- 고객사 환경에 맞춰 상품을 구성하고, 부가 항목은 협의해서 제안합니다.

**2026년에 추가된 신사업**
- 기계설비 성능점검(법정 점검)
- 에너지진단(연간 에너지 사용량 2,000toe 이상 사업자, 5년마다)
- 건물에너지관리(BEMS)로 확장하려는 방향

> **범위:** 서비스영업은 **신규 장비 판매나 설치 수주를 하지 않습니다.** 장비 판매는 삼성전자 본사 B2B 조직과 대리점이 맡습니다. 서비스영업은 이미 설치된 장비의 유지보수·세척·점검 계약을 팝니다. 아래 "신규"는 **새 유지보수 계약을 따오는 것**을 뜻합니다.

## 1. 신규 유지보수 계약 영업 [추정]
| 세부 업무 | 내용 |
|---|---|
| 타깃 발굴 | 시스템에어컨을 설치한 사업장(학교, 병원, 호텔, 오피스, 공장, 프랜차이즈, 상가) 목록 확보. 로지텍이 직접 설치하므로 **설치 이력 데이터가 영업 자산**이 됨 |
| 리드 소스 | 무상 보증기간이 끝나는 고객, 세척 프로모션 이용 고객, 대리점·시공 파트너가 소개한 고객, 삼성전자 본사 B2B 영업이 넘겨준 고객 |
| 방문 상담 | 시설팀장, 관리소장, 행정실(학교), 구매 담당자를 만나 필요를 파악하고 상품을 제안 |
| 현장 실사 | 협력사나 엔지니어와 함께 장비 수량, 용량, 연식, 상태를 확인 |
| 견적·제안서 | 장비 대수와 용량을 기준으로 단가를 내고, 상품과 부가 옵션을 조합. 경쟁사(하이엠솔루텍, 지역 설비업체)와 비교한 제안 |
| 계약 체결 | 보장 범위(소모품, 사용자 과실 제외 등)와 기간, 지급 조건을 정하고 계약을 시스템에 등록 |

## 2. 공공·법인 입찰 [추정]
- 학교, 교육청, 관공서, 공기업의 냉난방기 유지관리 용역 입찰에 참여합니다. 공고 확인, 제안서와 가격 산정, 서류 제출이 포함됩니다.
- 공공기관은 연초에 예산을 집행합니다. 그래서 **12~2월이 공공 계약 시즌**이 됩니다.
- 수능 시험장 점검 같은 공공 지원 활동은 공공 고객과의 관계를 관리하는 수단이기도 합니다.

## 3. 갱신·업셀·교체 연계 [추정]
| 세부 업무 | 내용 |
|---|---|
| 계약 갱신 | 연간 계약이 끝나기 1~2개월 전에 갱신 협의. 유지보수 영업에서 **가장 중요한 성과 지표(KPI)**일 가능성이 높음 |
| 상위 상품 전환 | 퍼스트마일에서 미들마일로, 원격케어나 공기청정 판넬 케어 추가 |
| 교체 수요 연계 | 노후 장비의 교체 필요성을 파악해 본사 B2B나 대리점에 **리드로 넘김**. 장비 판매 실적은 그쪽 몫이고, 서비스영업은 교체 후 유지보수 계약(라스트마일케어)을 잡음 |
| 신사업 교차 판매 | 기존 고객 중 성능점검이나 에너지진단 의무 대상 건물에 추가 계약 제안 |

## 4. 신사업 영업: 성능점검·에너지진단 [사실과 추정]
- [사실] 기계설비법에 따라 연면적 1만㎡ 이상 건축물(창고 제외) 등은 기계설비유지관리자를 선임해야 하고, 성능점검도 받아야 합니다. 위반하면 과태료가 부과됩니다.
- [사실] 에너지 다소비사업자(연간 2,000toe 이상)는 5년마다 에너지진단을 받아야 합니다.
- [추정] 대구·경북에는 대형 건물, 산업단지(성서·달성·구미), 병원, 대학이 많습니다. 이들을 대상으로 법정 점검을 영업하면 **규제가 만들어 주는 수요**를 잡을 수 있습니다.
- [추정] 사업을 막 시작한 단계라, 지역에서 처음 실적을 만드는 사람이 공을 크게 인정받습니다.

## 5. 서비스 이행·협력사 운영 [추정]
| 세부 업무 | 내용 |
|---|---|
| 일정 배정 | 계약 고객의 정기점검(연 2회)과 세척 일정을 협력사에 배정 |
| 협력사 관리 | 세척·점검 협력사(전국 36곳 중 권역 담당분)의 역량, 인력, 단가를 관리하고 신규 협력사를 발굴 |
| 품질 관리 | 점검 결과 보고서 검수, 현장 품질 점검(품질지도사와 협업), 클레임 대응 |
| 정산 | 협력사 작업 실적 정산, 고객 청구와 수금 확인 |
| 유관 부서 협조 | 고장 수리는 삼성전자서비스와 연계, 원격 이상 알림은 관제센터와 연계 |

## 6. 고객 관리·CS [추정]
- 점검 결과 리포트를 보내고 정기적으로 리뷰합니다.
- 긴급 상황(냉방이 멈춘 경우)에 바로출동을 연결하고 진행 상황을 고객에게 안내합니다.
- 핵심 고객(대형 병원, 대학, 공장)은 담당자를 지정해 관리합니다.

## 7. 실적·기획·보고 [추정]
- 권역 매출 목표를 관리합니다(신규 계약, 갱신율, 서비스 매출, 미수금).
- 영업 파이프라인을 관리하고 주간·월간 실적을 본사에 보고합니다.
- 지역 프로모션을 운영합니다(예: 봄 세척 프로모션).
- 차장급은 권역 담당자이거나 파트 리더로서 후배 영업사원 지도와 협력사 회의 주관까지 맡을 가능성이 큽니다.

## 8. 연간 업무 리듬 [추정]
| 시기 | 주요 업무 |
|---|---|
| 12~2월 | 계약 갱신 시즌, 공공 입찰, 연간 목표 수립 |
| 3~5월 | 냉방 전 세척과 점검 성수기, 세척 프로모션 |
| 6~8월 | 긴급출동 대응, 클레임 관리(가장 바쁜 현장 지원 시기) |
| 9~11월 | 난방 전 점검, 신규 계약 영업, 이듬해 예산 수요 발굴 |

## 9. 판매 경력과의 연결
| 판매에서 하던 일 | 서비스영업에서 바로 쓰는 곳 |
|---|---|
| 매장·채널 실적 관리 | 권역 KPI와 파이프라인 관리 |
| 백화점 MD 협상 | 시설팀·구매팀과의 계약 협상 |
| 판매 인력 관리 | 협력사 관리 |
| 행사·프로모션 운영 | 세척·점검 프로모션 운영 |
| 고객 컴플레인 대응 | 서비스 클레임 대응 |

**새로 배워야 할 것**
- 시스템에어컨 구조(실외기, 실내기, EHP와 GHP의 차이)
- 기계설비법, 성능점검 제도
- 공공 입찰 실무
- 견적을 내는 방식

## 10. 면접·입사 전 확인 질문
1. 대구 팀이 맡는 업무는 1~7번 중 어디까지인가요? 협력사 운영과 정산은 별도 팀이 하나요?
2. 개인 KPI는 무엇인가요? 신규 계약액, 갱신율, 서비스 매출, 미수금 중 어떤 것으로 평가하나요?
3. 대구·경북 계약 고객은 몇 곳이고, 담당 협력사는 몇 곳인가요? 기존 고객을 넘겨받나요?
4. 성능점검과 에너지진단 영업은 대구에서 이미 시작했나요?
5. 외근 비율은 어떻게 되나요? 차량이나 법인카드를 지원하나요?
6. 견적과 계약은 어떤 시스템으로 처리하나요? 필요한 교육은 무엇인가요?
